First-time PCAN-USB setup on Windows (one time only)
  1. Chrome can only open the PCAN-USB if Windows uses the generic WinUSB driver, not PEAK's driver.
  2. Download Zadig, plug in the PCAN-USB, and run Zadig.
  3. Menu Options → List All Devices, select PCAN-USB, choose WinUSB, click Replace Driver.
  4. Re-plug the adapter, then click Connect here and pick the PCAN-USB in Chrome's popup.
  5. To use PEAK tools such as PCAN-View again, reinstall the PEAK driver from Device Manager.

Zadig — USB driver installation made easy

For PCAN-USB in Chrome (WebUSB), Windows must use the generic WinUSB driver. Zadig installs that driver in one step.

Windows

How to install WinUSB with Zadig

  1. Download Zadig from the official site (portable — no install required).
  2. Plug in your PCAN-USB adapter.
  3. Open Zadig → Options → List All Devices.
  4. Select PCAN-USB, choose driver WinUSB, click Replace Driver.
  5. Unplug and re-plug the adapter, then click Connect above and choose PCAN-USB in Chrome.
